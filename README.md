# Система учета домашних заготовок (ПР1)

## Назначение
Программа предназначена для автоматизации учета домашних заготовок (консервации, варенья, солений), контроля сроков и партий, а также учета остатка банок в погребе или кладовой.

## Целевая аудитория
* Домохозяйства и семьи, занимающиеся сезонной консервацией;
* Садоводы и огородники;
* Любители домашнего консервирования.

## Предметная область
Предметная область включает процессы переработки сезонного сырья (овощи, ягоды, фрукты) в заготовки и учет готовой продукции по партиям с датами выработки.

## Требования и установка
* Python 3.10+
* Установка зависимостей:
```bash
pip install -r requirements.txt
```

## Запуск программы
```bash
python main.py
```

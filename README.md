# Система учета домашних заготовок

Консольное приложение на языке Python для автоматизации учета заготовок, сырья, партий консервации и контроля остатков банок в погребе или кладовой (Практические работы № 1 – № 3).

---

## Назначение
Программа предназначена для:
* Ведения каталога исходного сырья (продуктов);
* Учета рецептур и видов домашних заготовок;
* Регистрации изготовленных партий с указанием даты выработки и количества банок;
* Контроля расхода и списания банок из конкретных партий;
* Быстрого поиска заготовок и анализа запасов.

## Целевая аудитория
* Домохозяйства и семьи, заготавливающие консервацию на зиму;
* Владельцы приусадебных участков, дачники и садоводы;
* Любители домашнего консервирования, солений, джемов и сушеных запасов.

## Предметная область
Предметная область описывает жизненный цикл домашней консервации:
```text
[ Исходный продукт (сырье) ]
            │
            ▼ (основа рецепта)
    [ Вид заготовки ]
            │
            ▼ (изготовление в определенный день)
    [ Партия банок (дата, количество) ]
            │
            ▼ (потребление/списание)
    [ Учет остатков и статуса ]
```

## Основные сущности

### 1. `Product` (`models/products.py`)
Описывает базовое сырье или ингредиент (например, «Огурцы», «Томаты», «Клубника»).
* **Атрибуты:**
  * `id: int` — уникальный идентификатор;
  * `name: str` — наименование продукта;
  * `category: str` — категория (овощи, фрукты, ягоды, грибы и др.).
* **Методы:**
  * `__init__(product_id, name, category)` — конструктор с валидацией;
  * `__str__()` — строковое представление в формате `[#1] Огурцы (Категория: овощи)`;
  * `@staticmethod validate_name(name: str) -> bool` — проверка названия (непустая строка от 2 символов);
  * `@classmethod from_data(data: dict) -> Product` — фабричный метод создания из словаря;
  * `to_dict() -> dict` — сериализация объекта в словарь JSON.

### 2. `Preserve` (`models/preserves.py`)
Описывает рецепт или вид заготовки, агрегируя ссылку на экземпляр `Product`.
* **Атрибуты:**
  * `id: int` — уникальный идентификатор;
  * `name: str` — название заготовки;
  * `product: Product` — строгая ссылка на экземпляр `Product`;
  * `recipe_notes: str` — заметки к рецепту или условия хранения.
* **Методы:**
  * `__init__(preserve_id, name, product, recipe_notes)` — конструктор;
  * `__str__()` — формат `[#1] Заготовка: 'Маринованные огурцы' (Основной продукт: Огурцы)`;
  * `@classmethod from_data(data: dict, product: Product) -> Preserve` — фабрика из словаря и объекта `Product`;
  * `to_dict() -> dict` — сериализация с внешним ключом `product_id`.

### 3. `Batch` (`models/batches.py`)
Описывает изготовленную партию заготовок с датой и количеством банок.
* **Атрибуты:**
  * `id: int` — уникальный идентификатор партии;
  * `preserve: Preserve` — ссылка на экземпляр `Preserve`;
  * `production_date: str` — дата выработки (`ГГГГ-ММ-ДД`);
  * `quantity: int` — количество банок в наличии;
  * `is_consumed: bool` — признак полного расхода (`True`, если банок не осталось).
* **Методы:**
  * `__init__(batch_id, preserve, production_date, quantity)` — конструктор с валидацией остатка;
  * `__str__()` — формат `[Партия #1] 'Маринованные огурцы' от 2026-09-10: 8 шт. [АКТИВНА]`;
  * `consume(amount: int) -> bool` — бизнес-метод списания банок;
  * `@staticmethod validate_quantity(quantity: int) -> bool` — проверка на неотрицательное целое число;
  * `@classmethod from_data(data: dict, preserve: Preserve) -> Batch` — сборка из словаря и объекта заготовки;
  * `to_dict() -> dict` — сериализация с внешним ключом `preserve_id`.

## Основные операции
1. **Просмотр партий в погребе:** отображение текущих запасов, дат и статусов расхода.
2. **Просмотр каталога заготовок и сырья:** наглядный вывод доступных рецептур.
3. **Добавление сырья:** ввод новых наименований и категорий продуктов.
4. **Создание рецепта заготовки:** привязка к существующему сырью с примечаниями.
5. **Регистрация партии:** фиксация даты производства и стартового количества банок.
6. **Списание банок:** частичный или полный расход банок с автоматическим переводом партии в статус `[ИЗРАСХОДОВАНА]`.
7. **Поиск заготовок:** регистронезависимый поиск по фрагменту названия.
8. **Сортировка партий:** упорядочивание партий по дате выработки (свежие или ранние).
9. **Сохранение данных:** ручная запись и автосохранение при выходе из программы.

## Хранение данных
Данные сохраняются в каталоге `data/` в формате JSON:
* `data/products.json` — список исходных продуктов (`id`, `name`, `category`);
* `data/preserves.json` — рецепты заготовок (`id`, `name`, `product_id`, `recipe_notes`);
* `data/batches.json` — партии заготовок (`id`, `preserve_id`, `production_date`, `quantity`, `is_consumed`).

Слой `storage.py` обеспечивает безопасную обработку ошибок `FileNotFoundError` и `json.JSONDecodeError`.

## Требования и установка
* Python 3.10 или выше;
* Установка зависимостей:
```bash
pip install -r requirements.txt
```

## Запуск программы
Запуск основного консольного приложения:
```bash
python main.py
```
